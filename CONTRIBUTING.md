# Contributing

1. Open an issue describing the change and its read-only safety impact.
2. Create a focused branch and add tests.
3. Run `lint.bat`, `test.bat`, and `python scripts/security_scan.py`.
4. Keep live-network tests opt-in and never add wallet, authentication, execution, bypass, or secret-handling code.
5. Submit a pull request using the template.

By contributing, you agree that your contribution is licensed under MIT.
